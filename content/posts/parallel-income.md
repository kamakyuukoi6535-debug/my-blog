「FIRE（経済的自立と早期リタイア）」という言葉を聞いて、こう思ったことはありませんか？

<span class="hl-p">「1億円ためて仕事を辞める？　そんなの、自分には無理だ」</span>

たしかに、よくあるFIRE本のゴールはかなり遠い場所にあります。でも、この『「パラレルインカム」のはじめ方』が教えてくれるのは、<span class="hl-y">「仕事は辞めない。それでも自由になる」という第三の道</span>です。表紙にも「年収300万円からできる進化版FIRE」と書かれています。

![『「パラレルインカム」のはじめ方』（泉正人 著／ファイナンシャルアカデミー 監修／ディスカヴァー・トゥエンティワン）](/images/parallel-income-cover.jpg)

今回は、この本の考え方を、むずかしい言葉をできるだけ使わずに解説します。投資の知識がゼロでも、最後まで読めば「自分は次に何をすればいいのか」がはっきりするはずです。

## <span class="txt-blue">著者はどんな人？</span>

著者は泉正人（いずみ・まさと）さん。累計64万人が学んだといわれるマネースクール「ファイナンシャルアカデミー」の代表です。監修も同アカデミーが担当しています。

自分自身が会社を立ち上げ、気づけば「パラレルインカム」を実践していた——という体験がベースになっているので、<span class="hl-b">机上の空論ではなく、実際に歩いた道の話</span>として読めるのが特徴です。

## <span class="txt-blue">ポイント1：「お金のなる木」を2本持つ</span>

パラレルインカムとは、直訳すると<span class="hl-y">**「収入の複線化」**</span>。会社の給料という1本の線と並べて、もう1本の収入の線を通す、という意味です。

大事なのは、その2本目が<span class="txt-red">「アルバイト」ではない</span>ということ。

<span class="hl-b">労働所得（働いて得るお金） ＋ 資産所得（働かなくても入ってくるお金）</span>

これがパラレルインカムの正体です。本書では、これを<span class="hl-p">「お金のなる木を2本持つ」</span>と表現しています。1本目は自分で水をやり続ける木、2本目は勝手に実をつけてくれる木、というイメージです。

副業をもう1つ増やすのは、水やりする木を増やすのと同じ。収入は増えても、時間はどんどん減っていきます。目指すのは、そこではありません。<span class="hl-y">「休んでも止まらない流れ」を1本つくること</span>が、この本の出発点です。

## <span class="txt-blue">ポイント2：FIREとのいちばん大きな違いは「仕事を辞めないこと」</span>

FIREは「早期リタイア」、つまり仕事を辞めるのがゴールです。でも著者は、そこに疑問を投げかけます。

辞めたあと、時間を持て余してしまう人が意外と多いからです。

![FIREとパラレルインカムは、ゴールの置き方がまったく違う。](/images/parallel-income-vs-fire.jpg)

パラレルインカムでは、仕事は続けます。ただし、お金のためだけにイヤイヤ続ける仕事ではなく、<span class="hl-y">「好きだからやる仕事」に変えていく。</span>ここが決定的な違いです。

学校でも会社でも、「やらされている作業」と「自分で選んだ活動」では、同じ時間でも疲れ方がまるで違いますよね。パラレルインカムが目指すのは、後者の状態です。

さらに、仕事を続けることには現実的なメリットもあります。<span class="hl-b">**収入の柱が2本あれば、片方が不調でも生活は崩れません。**</span>株価が下がった年も給料は入るし、病気や転職で働けない時期があっても資産所得が支えてくれる。辞めないという選択は、安全装置でもあるのです。

## <span class="txt-blue">ポイント3：ゴールは「1億円」ではなく「生活費 ＜ 資産所得」</span>

この本のゴールラインは、とてもシンプルです。

<span class="hl-y">毎月の生活費を、資産所得が上回ること</span>

たとえば生活費が月20万円なら、資産所得が月20万円をこえた瞬間、あなたは「働かなくても生きていける状態」になります。そこから先の労働は、生活のためではなく、<span class="hl-p">やりたいからやる労働</span>に変わります。

「1億円」という数字を目標にすると気が遠くなりますが、「月20万円」なら、まだ手が届きそうに感じませんか。ゴールの置き方を変えるだけで、道のりの見え方は変わります。

しかも、このゴールにはもう1つの近づき方があります。それは、<span class="hl-b">生活費のほうを下げること。</span>生活費が月30万円の人と月18万円の人では、必要な資産所得がまったく違います。支出を見直すことは、我慢ではなく<span class="hl-y">ゴールラインを自分のほうへ引き寄せる作業</span>なのです。

## <span class="txt-blue">ポイント4：順番をまちがえない「4つのステップ」</span>

本書は、実現までの道のりを4つの段階に分けています。

![順番を飛ばさないことが、この本のいちばん実務的な教え。](/images/parallel-income-steps.jpg)

1. **労働所得を増やす**
2. **資産構築をする**（増えた分をためて、元手をつくる）
3. **資産所得をつくる**（元手を働かせる）
4. **仕事でも自己実現を達成する**

ここで大事なのは、<span class="hl-p">順番を飛ばさないこと</span>です。

いきなりステップ3から始めようとする人は、とても多い。でも元手がない状態で資産所得だけを追いかけるのは、<span class="hl-b">練習せずに試合に出るようなもの</span>です。まずは本業の収入を上げ、支出をコントロールして、種を確保する。地味ですが、ここが土台になります。

## <span class="txt-blue">ポイント5：「お金の7か条」から学ぶ、日常の習慣</span>

本書の第2章には、暮らしの中で効いてくる7つの心がまえがまとめられています。特に取り入れやすいのが、この2つです。

### <span class="txt-orange">① 欲しいものを買う前に、お金を迂回させる</span>

給料が入ったら、使う前に一部を別の場所へ「迂回」させる。いわゆる先取り貯蓄です。<span class="hl-y">残ったお金で暮らす仕組みにすれば、意志の強さに頼らなくてすみます。</span>

### <span class="txt-orange">② 資産運用は「自転車の運転」と考える</span>

自転車は、本を読んだだけでは乗れません。最初は転びます。でも一度乗れるようになれば、一生忘れない。運用も同じで、<span class="hl-p">小さく始めて体で覚えるもの</span>だ、という考え方です。

7か条にはほかにも、「お金に働いてもらうことをポジティブにとらえる」「投資の本当のリスクを知り、コントロールする」といった項目が並びます。<span class="hl-b">リスクはゼロにするものではなく、正体を知って手なずけるもの</span>——この姿勢が本書全体を貫いています。

## <span class="txt-blue">ポイント6：「失敗から学ぶ」より「成功から学ぶ」</span>

「失敗は成功のもと」とよく言われますが、著者の考え方は少しちがいます。

<span class="hl-y">失敗を避けるノウハウと、成功するノウハウは、別物だから</span>です。

失敗をいくら分析しても、それは「やってはいけないこと」のリストが増えるだけ。実際にうまくいっている人のやり方を聞いて、まねをするほうがずっと近道だ、と本書は言います。

部活でも、ケガの原因を研究するより、うまい先輩のフォームを見よう見まねでコピーするほうが上達が早い——そんな感覚に近いかもしれません。ただし、まねる相手は<span class="hl-p">自分が行きたい場所に実際にたどり着いた人</span>を選ぶこと。SNSにあふれる成功談を見分ける目だけは、自分で育てる必要があります。

## <span class="txt-blue">ポイント7：「FIREの5倍ラク」の根拠と、その注意点</span>

本書のタイトルにもなっている「進化版FIRE」。著者はパラレルインカムを<span class="hl-y">**「FIREの5倍ラク」**</span>と表現します。

その根拠が、この対比です。

| | 年400万円を得るために必要な元手 |
|---|---|
| FIREの「4%ルール」 | **1億円** |
| 不動産の「20%ルール」 | **2,000万円** |

金額が5分の1になるから「5倍ラク」というわけです。本書が資産所得の手段として不動産投資をすすめているのは、この効率の良さが理由です。

ただし、ここは正直に書いておきます。<span class="txt-red">この計算は、借入（ローン）を使うことが前提です。</span>空室、修繕、災害、金利の上昇といったリスクもあり、株式のインデックス投資とくらべて、必要な知識と手間は明らかに多くなります。

<span class="hl-b">**「5倍ラク」は「5倍かんたん」ではない。**</span>この点については、記事の後半で、実際に賃貸経営をしている立場から詳しくお話しします。

## <span class="txt-blue">ポイント8：最後に手に入るのは「5つの自由」</span>

では、これだけの手間をかけて、何が手に入るのか。本書は5つを挙げています。

1. **お金の自由**——値段ではなく「最善かどうか」で選べる
2. **時間の自由**——24時間を自分の意思で使える
3. **住処の自由**——住む場所を仕事に縛られず決められる
4. **人間関係の自由**——つき合いたい人とだけつき合える
5. **仕事の自由**——やりたい仕事だけを選べる

巻末には、実際にパラレルインカムを実現した6人の物語も収められています。独立した人、ハワイや沖縄へ移り住んだ人、趣味の釣りに時間を使う人、夢だった作曲の仕事に切り替えた人、50代でアメリカ留学に挑戦した人——選んだ道は全員バラバラです。著者が<span class="hl-p">「パラレルインカムは100人100とおり」</span>と書いているとおり、正解は1つではありません。

つまり、この本のゴールはお金そのものではありません。<span class="hl-y">**手に入れたいのは「選択肢」**</span>なのです。お金がないと、選択肢の数がどんどん減ってしまう。だからお金を増やす——という順番で語られている点が、この本の誠実なところだと思います。

## <span class="txt-blue">実際に「2本目の柱」を持ってみて感じたこと</span>

ここからは、私自身の話をさせてください。

この本を手に取ったとき、私はすでに賃貸用の戸建てを2軒所有し、<span class="txt-orange">毎月合計15万7,000円</span>の家賃収入を得ている状態でした。だからでしょうか。読み進めるうちに、<span class="hl-b">「これは今の自分の生き方や考え方を、そのまま言葉にしてくれている本だ」</span>と何度も感じたのです。

### <span class="txt-orange">金額よりも大きかったのは「心の余裕」</span>

給与だけに頼らず、もう一つの収入の柱を持つことで、<span class="hl-y">**精神的な安心感は驚くほど大きくなります。**</span>会社員としての給与に加えて家賃収入があることで、将来のお金に対する漠然とした不安は、ずいぶん和らぎました。

これは金額の問題だけではありません。

<span class="hl-p">「収入源が一つではない」という事実そのものが、心の余裕をつくってくれる</span>

本書がくり返し「精神的な自由」を語る理由が、実感としてよくわかります。

### <span class="txt-orange">でも、「チャリンチャリン」ではありません</span>

一方で、これははっきり書いておきたいのですが、<span class="txt-red">不動産賃貸業は「何もしなくても儲かる」世界ではありません。</span>

空室リスク、設備の故障や修繕費、入居者対応、近隣トラブル——オーナーとして向き合わなければならない課題は、決して少なくありません。毎月家賃が振り込まれる姿だけを見れば楽そうに映るかもしれませんが、その裏側には、<span class="hl-b">リスク管理と判断の積み重ね</span>があります。実際に運営してきたからこそ、誰にでも簡単にできるものではないと感じています。

正直に言えば、今の投資環境をふまえて<span class="hl-y">「もしゼロから資産形成を始めるなら、低コストのインデックス投資一本でも十分ではないか」</span>と考えることもあります。長期・積立・分散を基本としたインデックス投資は、それだけ優れた方法だからです。

### <span class="txt-orange">それでも続けている理由</span>

では、なぜ私は不動産賃貸業を続けているのか。改めて考えてみて気づいたのは、結局のところ<span class="hl-p">**「好きだから」**</span>でした。

物件を探し、購入し、手を加え、入居者の方に住んでいただく。その一連の流れそのものに面白さを感じています。収益だけを追いかけるのではなく、自分の興味や楽しさも含めて取り組めているからこそ、長く続けられているのだと思います。

これはまさに、本書のポイント2で紹介した<span class="hl-b">**「好きだからやる仕事に変えていく」**</span>という考え方そのものかもしれません。資産所得づくりもまた、自分に合った、続けられる方法を選ぶのがいちばんなのです。

### <span class="txt-orange">今日からできる3つのこと</span>

1. **自分の「生活費のライン」を計算してみる**（1億円ではなく、月◯万円がゴール。まずは家計簿で現在地を知る）
2. **給料日に「先に取り分ける」仕組みをつくる**（余ったら貯める、では一生たまりません）
3. **順番どおりに進める**（いきなり資産所得を狙わず、まずは収入を上げて種をつくる）

パラレルインカムは、単に収入を増やすためのテクニックではありません。<span class="hl-y">収入源を複数持つことで人生の選択肢を広げ、精神的な自由を手に入れるための考え方</span>です。

私自身、給与所得と不動産所得という二つの柱を持てたことで、将来のお金に対する心配は以前よりずっと小さくなりました。そしてその安心感は、日々の生活や仕事にも良い影響を与えてくれています。

<span class="hl-p">2本目の柱が不動産である必要はありません。</span>インデックス投資でも、配当株でも、自分に合った方法で構わない。大事なのは、<span class="hl-b">「給与が止まっても、何かが入ってくる」という状態を少しずつつくっていくこと</span>です。

FIREという言葉に「自分には関係ない」と感じていた方ほど、この本は効きます。これから給与以外の収入を持ちたい、将来への不安を減らしたいと考えている方にとって、自分らしい働き方や生き方を考えるきっかけをくれる一冊です。

気になった方は、ぜひ本書も手に取ってみてください。
